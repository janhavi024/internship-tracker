# Internship Tracker

A cloud-based internship management system built using HTML, CSS, JavaScript and Supabase.

## Features

* User Authentication using Supabase Auth
* Internship Application Tracking
* Resume Upload using Supabase Storage
* Search Applications
* Dashboard Statistics
* CRUD Operations (Create, Read, Update, Delete)
* Status Tracking (Applied, OA Cleared, Interview Scheduled, Selected, Rejected)

## Tech Stack

* HTML
* CSS
* JavaScript
* Supabase Authentication
* PostgreSQL Database
* Supabase Storage

## Project Overview

The Internship Tracker helps students manage internship applications from a centralized dashboard. Users can securely log in, store application details, upload resumes, track application status, and monitor their progress through dashboard analytics.

## Cloud Services Used

* Authentication as a Service (Supabase Auth)
* Database as a Service (PostgreSQL)
* Storage as a Service (Supabase Storage)
